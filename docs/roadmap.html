Roadmap — 3.6 and beyond

Forward-looking roadmap targets, subject to change. Everything on this page is derived from [FINAL] Red Hat AI - Q3 2026 - What's New & What's Next (Q3 2026 edition). These are targets, not commitments: the deck states that any forward-looking statements are subject to change, and no production SLA applies until a feature ships in a tracked release and its status is confirmed by official release notes. Statuses here use the deck's own labels (GA / TP / DP) as targets, and windows use the deck's cadence language (Fast 1, EA1/EA2, GA, Q4 2026, 1H 2027, 3.7, “uncommitted”). Shipped status history lives in the Feature Matrix.

How this page relates to the rest of the tracker

Not in the shipped timeline

Planned targets live in a separate roadmap layer. A feature's status history and current status only change when a release actually ships and the release notes confirm it — so the Feature Matrix shows planned cells as dashed marks, never as shipped fact.

Planned breaking changes

Breaking changes the deck announces ahead of time (removals, renames, deprecations) are also listed on the Migration Checklist as “planned changes” with actionable migration notes.

Source precedence

Roadmap decks sit below release notes, product guides, and the Supported Configurations matrix. Where the deck's “What's New” claims disagree with tracked sources, it is recorded on Source Conflicts, not silently resolved.
